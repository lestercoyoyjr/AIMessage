# AIMessage — Research foundation

20 papers on inter-agent communication and shared/distributed memory. All arXiv IDs were
fetch-verified against `arxiv.org/abs/<ID>`.

## Read these 7 first (sequenced prerequisites)

1. **Collaborative Memory** — [2505.18279](https://arxiv.org/abs/2505.18279) — private+shared tiers, provenance-tagged fragments, bipartite-graph access control. *Your access-control model.*
2. **Portable Agent Memory** — [2605.11032](https://arxiv.org/abs/2605.11032) — cryptographically-verified memory transfer across heterogeneous agents. *Your wire format — read before designing one.*
3. **Internet of Agents** — [2407.07061](https://arxiv.org/abs/2407.07061) — IM-style protocol, heterogeneous agent discovery + dynamic teams. *Closest prior art; study what to omit.*
4. **Agent Network Protocol (ANP) white paper** — [2508.00007](https://arxiv.org/abs/2508.00007) — DID-based identity + three-layer AI-native protocol. *Your identity layer.*
5. **LLM Agent Communication Security Survey** — [2506.19676](https://arxiv.org/abs/2506.19676) — risks + defenses across user/agent/resource layers. *Your threat checklist.*
6. **MCP: Landscape, Security Threats** — [2503.23278](https://arxiv.org/abs/2503.23278) — MCP lifecycle + threat taxonomy. *Before shipping MCP-server sharing (Phase 4).*
7. **LTM Security / Mnemonic Sovereignty** — [2604.16548](https://arxiv.org/abs/2604.16548) — names the post-deletion "forget" gap. *Before the erasure model (Phase 5).*
